pixel art drawing application is a 28*8 grid pixel art editor where you can make pixel art with limited amount of colors and includes a erasure feature


features:
1)Draw pixel art by clicking on the grid
2)multiple colour palette
3)erasure tool
4)an interactive painting system

languages used:
-html
-css
-Javascript

instructions to use:

1)select a color from the palette
2)click on any box in the grid
3)select the eraser tool to remove colours
4)create your own pixel art
